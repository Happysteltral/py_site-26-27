  • Toon het grootste getal

14. Uitdaging¶

Maak een klein puntenprogramma.

Vereisten¶

  • Gebruik een lijst met punten
  • Toon alle punten
  • Toon het gemiddelde
  • Toon het hoogste punt
  • Toon het laagste punt

Extra uitdaging

Laat de gebruiker zelf punten toevoegen via input().

15. Mini-project¶

Klassenlijst beheren¶

Maak een programma waarmee je:

  • namen toevoegt
  • namen verwijdert
  • alle namen toont
  • controleert of een leerling aanwezig is

Voorbeeld:

1. Naam toevoegen
2. Naam verwijderen
3. Toon lijst
4. Zoek leerling

Uitbreiding

Voeg een menu toe met een while-lus zodat het programma blijft werken tot de gebruiker stopt.
